# Unit-тестирование

## Стек и конфигурация

Тесты запускаются через Vitest в `jsdom`. Vue SFC обрабатываются тем же плагином и с теми же alias, что и приложение, потому что секция `test` добавлена прямо в `vite.config.ts`. Для монтирования Vue-компонентов используется Vue Test Utils.

Общий файл `tests/setup.ts` автоматически размонтирует wrapper после каждого теста, очищает DOM и изменённые стили `body`, возвращает реальные таймеры и предоставляет безопасный mock `window.scrollTo` для модальных окон. Vitest также очищает и восстанавливает mocks между тестами.

Browser Mode не используется: для этого набора быстрых изолированных unit-тестов `jsdom` достаточно, а браузерный провайдер добавил бы Playwright и существенно утяжелил зависимости и запуск.

## Расположение и состав

Файлы `*.test.ts` находятся рядом с тестируемыми компонентами. Проверяется только согласованный набор:

- `src/components`: Button, CardApp, FooterApp, HeaderApp, все Inputs, Loader, обе Modals, ReviewItem и SingleSliderList;
- `src/views/favorite`: FavoriteList;
- `src/views/home/components`: HeroCard и HeroSlider.

Тесты проверяют публичное поведение: props, slots, отображаемые состояния, пользовательский ввод и клики, emits, маршруты ссылок и важные граничные случаи. Router, Pinia stores, composables, YouTube-player, Swiper и сложные дочерние компоненты заменяются локальными минимальными stubs/mocks. Реальные API-запросы не выполняются.

## Команды

Watch-режим:

```sh
npm test
```

Однократный запуск всех unit-тестов:

```sh
npm run test:run
```

Статический HTML-отчёт Vitest UI:

```sh
npm run test:ui
```

Команда однократно запускает тесты с HTML-репортёром, сохраняет отчёт в `.vitest`, поднимает локальный Vite preview и открывает отчёт в браузере. Отчёт доступен только для просмотра и не требует токена. Preview работает, пока процесс не будет остановлен сочетанием `Ctrl+C`.

Отдельный файл:

```sh
npm run test:run -- src/components/Button/ButtonApp.test.ts
```

Coverage не настроен: для текущей задачи он не требуется, а обязательные пороги не дают дополнительной ценности поведению компонентов.
